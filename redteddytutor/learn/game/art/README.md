# Art (Teddy's Bakery)

Teddy is the brand's own 3D plush renders, supplied by the owner and cut out of their studio
backgrounds: `teddy-think.webp` (paw to chin; calm and working) and `teddy-cheer.webp` (arms up;
right answers and celebrations). To add a pose, cut it out to a transparent WebP with the feet at
the bottom edge, name it `teddy-<pose>.webp`, and add it to `TEDDY_POSES` in `js/teddy.js`.

The props and the shop are original vector artwork generated by `scripts/build-bakery-art.mjs`
(run `node scripts/build-bakery-art.mjs` after editing it).

| File | Used for |
|---|---|
| `teddy-think.webp`, `teddy-cheer.webp` | Teddy's poses (`js/teddy.js`) |
| `bun`, `bun-pink`, `bun-choc` | Counting and comparing rounds |
| `tray`, `plate` | Counting tray, comparing plates |
| `tin-*`, `cookie-*` | Shape rounds: a biscuit is dragged into the tin it fits |
| `macaron-*` | Pattern rounds |
| `shop` | The shop backdrop |

The scene loads these in `BakeryScene.preload`. Any file that fails to load falls back to the
code-drawn version, so art can be replaced one file at a time. To swap in raster art (for
example generated renders of the plush Teddy), keep the same key and size and change the
loader entry in `js/bakery.js` from `load.svg` to `load.image`.
