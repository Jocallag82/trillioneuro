# Art (Teddy's Bakery)

All illustrations here are original vector artwork generated by `scripts/build-bakery-art.mjs`
(run `node scripts/build-bakery-art.mjs` after editing it). One template draws Teddy, so every
pose keeps the brand mark's proportions, deep red plush, cream muzzle, navy scarf and gold star.

| File | Used for |
|---|---|
| `teddy-smile`, `teddy-blink`, `teddy-happy`, `teddy-think`, `teddy-oops`, `teddy-cheer` | Teddy's moods (`js/teddy.js`) |
| `bun`, `bun-pink`, `bun-choc` | Counting and comparing rounds |
| `tray`, `plate` | Counting tray, comparing plates |
| `tin-*`, `cookie-*` | Shape rounds: a biscuit is dragged into the tin it fits |
| `macaron-*` | Pattern rounds |
| `shop` | The shop backdrop |

The scene loads these in `BakeryScene.preload`. Any file that fails to load falls back to the
code-drawn version, so art can be replaced one file at a time. To swap in raster art (for
example generated renders of the plush Teddy), keep the same key and size and change the
loader entry in `js/bakery.js` from `load.svg` to `load.image`.
